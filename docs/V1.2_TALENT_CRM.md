# TALENTFLOW MARKETPLACE V1.2 — EMPLOYER TALENT CRM, SAVED CANDIDATES & TALENT POOLS

**Release Version**: V1.2.0  
**Feature Scope**: Pre-application Talent Discovery, Saved Candidates, Favorites, Employer Talent Pools, Candidate Invitations, In-app & Email Notifications, and Hiring Pipeline Integration.

---

## 1. Executive Summary

TalentFlow V1.2 introduces a full-featured Employer Talent CRM empowering employers to discover, save, categorize, and invite top candidate talent before an official job application is submitted:
- **Discoverability Control**: `profileDiscoverable: Boolean @default(true)` on `CandidateProfile`.
- **Saved Candidates & Favorites**: Employer-scoped candidate bookmarking (`SavedCandidate`) with fast favorite filtering.
- **Employer Talent Pools**: Custom named candidate pools (`TalentPool` & `TalentPoolMember`) with member count tracking.
- **Invite-to-Apply Workflow**: Employer sends job invitations (`CandidateInvitation` with statuses `PENDING`, `VIEWED`, `ACCEPTED`, `DECLINED`, `EXPIRED`, `CANCELLED`).
- **Seamless Application Conversion**: When a candidate accepts an invitation, standard application creation is triggered, seamlessly handing off the applicant to the V1.1 Hiring Pipeline.
- **Security & Authorization**: BOLA/IDOR protection prevents unauthorized access to candidate pools, invitations, or saved candidates across different employers and candidates.

## 2. Database Schema Additions (`prisma/schema.prisma`)

```prisma
enum InvitationStatus {
  PENDING
  VIEWED
  ACCEPTED
  DECLINED
  EXPIRED
  CANCELLED
}

model SavedCandidate {
  id          String           @id @default(uuid())
  employerId  String
  candidateId String
  isFavorite  Boolean          @default(false)
  createdAt   DateTime         @default(now())

  employer    EmployerProfile  @relation(fields: [employerId], references: [id], onDelete: Cascade)
  candidate   CandidateProfile @relation(fields: [candidateId], references: [id], onDelete: Cascade)

  @@unique([employerId, candidateId])
  @@index([employerId])
}

model TalentPool {
  id          String             @id @default(uuid())
  employerId  String
  name        String
  description String?
  createdAt   DateTime           @default(now())
  updatedAt   DateTime           @updatedAt

  employer    EmployerProfile    @relation(fields: [employerId], references: [id], onDelete: Cascade)
  members     TalentPoolMember[]

  @@index([employerId])
}

model TalentPoolMember {
  id            String           @id @default(uuid())
  talentPoolId  String
  candidateId   String
  addedAt       DateTime         @default(now())

  talentPool    TalentPool       @relation(fields: [talentPoolId], references: [id], onDelete: Cascade)
  candidate     CandidateProfile @relation(fields: [candidateId], references: [id], onDelete: Cascade)

  @@unique([talentPoolId, candidateId])
  @@index([talentPoolId])
}

model CandidateInvitation {
  id            String           @id @default(uuid())
  employerId    String
  candidateId   String
  jobId         String
  status        InvitationStatus @default(PENDING)
  message       String?
  expiresAt     DateTime?
  applicationId String?
  createdAt     DateTime         @default(now())
  updatedAt     DateTime         @updatedAt

  employer      EmployerProfile  @relation(fields: [employerId], references: [id], onDelete: Cascade)
  candidate     CandidateProfile @relation(fields: [candidateId], references: [id], onDelete: Cascade)
  job           Job              @relation(fields: [jobId], references: [id], onDelete: Cascade)

  @@index([employerId, candidateId])
  @@index([candidateId])
  @@index([jobId])
}
```

## 3. REST API Endpoints (`/api/v1/talent-crm/`)

- `GET /talent-crm/search`: Search discoverable candidate talent.
- `POST /talent-crm/saved/:candidateId`: Save candidate / toggle favorite.
- `DELETE /talent-crm/saved/:candidateId`: Unsave candidate.
- `GET /talent-crm/saved`: List saved candidates.
- `POST /talent-crm/pools`: Create talent pool.
- `GET /talent-crm/pools`: List talent pools.
- `GET /talent-crm/pools/:id`: Get pool detail with members.
- `PATCH /talent-crm/pools/:id`: Update pool.
- `DELETE /talent-crm/pools/:id`: Delete pool.
- `POST /talent-crm/pools/:id/members/:candidateId`: Add candidate to pool.
- `DELETE /talent-crm/pools/:id/members/:candidateId`: Remove candidate from pool.
- `POST /talent-crm/invitations`: Invite candidate to apply to job.
- `GET /talent-crm/invitations/employer`: List invitations sent by employer.
- `GET /talent-crm/invitations/candidate`: List invitations received by candidate.
- `PATCH /talent-crm/invitations/:id/decline`: Candidate declines invitation.
- `PATCH /talent-crm/invitations/:id/cancel`: Employer cancels invitation.
- `POST /talent-crm/invitations/:id/accept-and-apply`: Candidate accepts invitation and converts to application.
- `GET /talent-crm/analytics`: Employer CRM analytics dashboard metrics.
- `GET /talent-crm/admin/analytics`: Admin aggregate CRM conversion metrics.
