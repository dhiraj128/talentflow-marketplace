## 3. Matching Engine V2 Architecture

### Deterministic Score & Explainable Reasons Formula
Scoring is calculated deterministically from real candidate and job data:
1. **Required Skill Overlap (50%)**: Match ratio of candidate skills vs required job skills.
2. **Experience Level / Compatibility (20%)**: Compare candidate experience text vs job title/description.
3. **Location / Remote Preference (15%)**: Exact/partial location match or remote flexibility.
4. **Education Level (10%)**: Degree / education profile satisfaction.
5. **Profile Completeness (5%)**: Full name, title, bio, resume, avatar present.

### Employer Candidate Recommendations
Added `GET /api/v1/jobs/:id/recommended-candidates` for employers to view ranked discoverable candidates (`profileDiscoverable = true`) matching an owned job posting.

## 4. API Endpoints Introduced / Upgraded

- `GET /api/v1/jobs`: Advanced search supporting `q`, `skills`, `location`, `remote`, `type`, `postedWithin`, `sort`, `page`, `limit`.
- `GET /api/v1/jobs/recommended`: Deterministic Candidate $\rightarrow$ Job matching.
- `GET /api/v1/jobs/:id/recommended-candidates`: Deterministic Job $\rightarrow$ Candidates recommendations for employers.
- `GET / POST / DELETE /api/v1/saved-searches`: Authenticated saved searches with BOLA ownership protection.
- `GET / POST / DELETE /api/v1/job-alerts`: Candidate job alerts with automated execution cycle (`POST /api/v1/job-alerts/run-cycle`), duplicate delivery prevention (`JobAlertDelivery`), Resend emails, and Notification Center integration.
- `GET / DELETE /api/v1/search-analytics/history`: User search history.
- `GET /api/v1/search-analytics/admin/overview`: Admin search analytics insights.
