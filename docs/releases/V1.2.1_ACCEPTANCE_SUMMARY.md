## 2. Recommendation Algorithm Specification

The deterministic V1 algorithm computes match score from real Prisma database records:
$$\text{MatchScore} = \text{BaseScore (50)} + \text{SkillScore (up to 40)} + \text{LocationScore (5-10)}$$
- **Skill Score**: $15 \times (\text{Candidate Skills } \cap \text{ Job Required Skills})$ (capped at +40).
- **Location Score**: +10 for exact location match, +5 for Remote flexibility.
- **Match Score Range**: 50% to 99% (no hard-coded or fabricated scores).
- **Matching Reasons**: Array of matching criteria strings generated directly from matched fields.
