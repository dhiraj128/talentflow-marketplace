## 1. Overview & Architecture Summary

TalentFlow Marketplace V1.0.0 is the official initial production release of the full-stack talent, recruitment, freelancing, and training marketplace platform.

- **Frontend**: Next.js App Router (120 Static/Dynamic routes compiled cleanly) on Vercel.
- **Backend API**: NestJS REST API with Prisma ORM on Render containers.
- **Database**: Render PostgreSQL with SSL (`sslmode=require`).
- **File Storage**: AWS S3 private resume storage with time-bound pre-signed URLs.
- **Email Service**: Resend transactional email provider (`TalentFlow <noreply@sispl.shop>`).
- **DNS / Domain**: Cloudflare proxy with TLS 1.3 encryption (`sispl.shop`, `api.sispl.shop`).

## 2. Key Role Capabilities & Features

### Candidate Marketplace
- Account registration, JWT authentication, Google/GitHub OAuth.
- Profile management, resume upload (5MB max PDF/DOCX), pre-signed resume URL preview.
- Job search, bookmarking, filter by location/salary/type, single-click job application.
- Unique application constraint (`jobId`, `candidateId`) preventing duplicate submissions.
- Notification Center V1.1 and transactional email alerts for application status changes.

### Employer Hiring Portal
- Company profile creation, job posting, job editing.
- Application management pipeline (Received $\rightarrow$ Shortlisted $\rightarrow$ Interviewing $\rightarrow$ Hired/Rejected).
- Authorized pre-signed candidate resume access.
- Interview scheduling, rescheduling, and notification dispatch.
- Strict role isolation preventing Employer A from inspecting Employer B jobs/applicants.

### Freelancer Marketplace
- Freelancer profile creation, skills catalog, hourly rate configuration, service publishing.
- Public talent discovery indexing (`/find-freelancers`).
- Deferred escrow/payment gateway features marked `OUT OF SCOPE` for V1.1/V2.

### Trainer & Course Portal
- Trainer profile creation, course creation with DRAFT status.
- Moderation workflow: DRAFT $\rightarrow$ Admin Review $\rightarrow$ PUBLISHED.
- Student enrollment discovery (`/find-courses`).

### Admin Operations Portal
- Admin Dashboard with real PostgreSQL platform aggregate metrics.
- User management, identity verification document review, candidate profile review.
- Moderation pipelines for job postings and trainer course submissions.
- Strict backend authorization (`RolesGuard` `@Roles(Role.ADMIN)`) on all `/api/v1/admin/*` APIs.

## 3. Core Technical Milestones

- **Authentication & Recovery**: Login, logout, single-use hashed OTP email delivery, password reset, and token revocation.
- **Notification Center V1.1**: Real unread badge count, dropdown, `/notifications` page, 30s auto-refresh, and resource target routing.
- **Production Observability V1**: `X-Request-ID` header correlation, structured duration logging, log redaction of secrets, `/health` and `/health/ready` endpoints.
- **Database Disaster Recovery**: 13/13 core entity schema & count matching in isolated restore drill, 7/7 restore safety guard checks passed.
- **OWASP Security Hardening V1**: Strict CORS origin policy, diagnostic endpoint RBAC, global `ValidationPipe` mass assignment rejection, 0 exposed secrets.
- **Browser Automation Suite**: 30/30 Playwright E2E tests PASSED across Chromium, Firefox, and WebKit.

## 4. Known Documented Limitations

1. **AWS S3 Bucket Versioning**: S3 Bucket Versioning is currently **DISABLED**. Private pre-signed URLs and Block Public Access are operational, but bucket versioning enablement is logged in `docs/V1.1_BACKLOG.md`.
2. **Legal Review**: Privacy Policy (`/privacy`) and Terms of Service (`/terms`) are published, but professional legal counsel review is recommended.
