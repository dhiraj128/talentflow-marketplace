## Highlights & Fixes

### 1. NestJS Controller Route Precedence Bug Fix
- **Root Cause**: In `talentflow-backend/src/jobs/jobs.controller.ts`, dynamic parameter `@Get(':id')` was defined BEFORE static routes like `@Get('saved/my-saved-jobs')` and `@Get('recommended')`. Requests to static endpoints were captured by `:id` = `'saved'`, returning 404 / 500 API errors and triggering generic frontend catch blocks.
- **Fix**: Re-ordered `JobsController` routes so all static endpoints (`@Get('saved/my-saved-jobs')`, `@Get('recommended')`, `@Get('employer/me')`, `@Get('admin/pending')`) precede dynamic `@Get(':id')`.

### 2. Deterministic Recommendation Engine (`GET /jobs/recommended`)
- **Backend Service**: Implemented `JobsService.getRecommendedJobs(userId)` querying real PostgreSQL CandidateProfile skills and matching against active Job required skills.
- **Deterministic Match Scoring**: Computes real match scores (0-100%) and matching reasons (e.g. "2 matching skills", "Location match", "Remote flexibility").
- **Zero Fabricated Scores**: Completely eliminates arbitrary/hard-coded percentages ("98% Match").

### 3. Frontend Candidate Page UX State Refactoring
- **Saved Jobs Page (`/job-seeker/saved-jobs`)**:
  - Differentiates 401 (Unauthenticated $\rightarrow$ "Sign in to view saved jobs"), 403 (Forbidden $\rightarrow$ "Candidate account required"), 200 with Data, 200 with 0 Records ("No saved jobs yet"), and 500 (API Error $\rightarrow$ "Unable to load saved jobs. Please try again" with Retry button).
- **Recommended Jobs Page (`/job-seeker/recommended`)**:
  - Connected to `GET /jobs/recommended`.
  - Displays real match score badges and matching reasons.
  - Handles incomplete profile, empty recommendations state, and error state with Retry button.

### 4. SavedJob Database Model & Verification
- Database table `SavedJob` with foreign keys to `CandidateProfile` and `Job`, unique constraint on `[candidateId, jobId]`, and safe forward migration `20260731130000_saved_jobs`.
